## Determination

- This manuscript is a full primary research report with Introduction, Methods, Results and Discussion, so the appropriate type is **Article**.
- Current Article limits: abstract ≤250 words; main text ≤5,000 words; ≤6 tables and figures combined; ≤50 references.
- The values 150 / 1,000 / 3 / 20 are the **Brief Communication** row of the same table, not Article limits.
- Package as built: abstract 239, main text 4,045 (main text + abstract 4,284, a stricter check), 5 figures + 1 table, 31 references. It meets every Article limit.
