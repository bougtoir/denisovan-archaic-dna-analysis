======================================================================
GLOBAL AUTHOR-VOICE RULE
======================================================================

Because this is a single-author paper, remove inappropriate first-person plural authorial language.

Default preference:

1. Use "I" / "my" / "me" where explicit author agency is useful and natural.
2. Use neutral active constructions where cleaner.
3. Use passive voice sparingly when it improves scientific style.
4. Do NOT mechanically replace every occurrence of "we" with "I" if "we" refers genuinely to:
   - humans collectively,
   - readers and author together,
   - a general scientific community,
   - a quoted phrase,
   - a cited study with multiple authors.

Every occurrence must be interpreted in context.

Examples:

AUTHORIAL:
"We analysed publicly archived segment calls..."
→ "I analysed publicly archived segment calls..."

AUTHORIAL:
"We ask three questions."
→ "I ask three questions."
or, preferably if stylistically stronger:
"This study addresses three questions."

AUTHORIAL:
"Our results show..."
→ "The results show..."
or:
"I found that..."
Choose the more natural scientific phrasing.

AUTHORIAL:
"Our analysis does not identify..."
→ "The analysis does not identify..."

NOT AUTHORIAL:
"We know that population structure..."
If this means the scientific community generally, do NOT automatically convert to "I know".

"I interpret..."

where appropriate.
