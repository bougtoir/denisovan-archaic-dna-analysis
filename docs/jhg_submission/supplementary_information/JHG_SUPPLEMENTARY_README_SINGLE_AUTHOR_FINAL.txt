Supplementary information read-me
Journal of Human Genetics submission: "A structural null for exceptional pairwise genomic similarity: archaic-segment sharing across 66 human populations"

Files (3):
1. JHG_SUPPORTING_INFORMATION_SINGLE_AUTHOR_FINAL.docx (Microsoft Word document)
   Supplementary Figures S1-S7 and Supplementary Table S1, with legends, plus
   descriptions of Supplementary Data 1-10. Open with Microsoft Word,
   LibreOffice Writer, or any viewer that reads .docx.
2. JHG_Supplementary_Data.zip (ZIP archive of plain-text CSV and JSON files)
   Supplementary Data 1-10: population metadata, all 2 145 pairwise
   similarity values with residuals and q values, model summaries, robustness
   tables, ABO focal-window results, ancient ABO summaries, and provenance with
   SHA-256 checksums. Unzip with any archive tool; open CSV files with a
   spreadsheet program or R/Python, and JSON files with a text editor.
3. JHG_SUPPLEMENTARY_README_SINGLE_AUTHOR_FINAL.txt (plain text)
   This file.

The analysis code that produced every file is publicly available at
https://github.com/bougtoir/denisovan-archaic-dna-analysis. Source segment
calls: Zenodo record 14136628 (https://doi.org/10.5281/zenodo.14136628).
