# NEGATIVE_RESULT_INTERPRETATION_AUDIT

The central pair-level result is negative (0 of 1,891 non-admixed pairs supported). Does the manuscript answer the eight required questions?

1. **Why is zero supported pairs scientifically informative?**
   ANSWERED. Discussion ¶1: "The finding that matters is not the absence of outliers ... but the demonstration that the expectation against which outliers are judged can be constructed, and that it is substantially different from the implicit expectation used when pairs are inspected one at a time." Results §2 reports nominal residuals up to z=2.21/2.53 that dissolve under the correct null — the informative contrast.

2. **Could this simply be low power?**
   ANSWERED. Discussion ¶6: the joint criterion "will detect only a substantial excess, so a real but modest pair-specific effect would not be recovered here".

3. **Is the threshold too conservative?**
   ANSWERED (implicitly + explicitly). z>2 + BH-FDR at q<0.10 is prespecified and conventional; nominal ranks retained in the pairwise table "for auditability" so readers can apply other thresholds; "deliberately conservative" conceded (Discussion ¶6).

4. **Are the largest residuals informative?**
   ANSWERED. Largest residuals reported numerically (z=2.21, q=0.78; z=2.53, q=0.82) and interpreted as "an upper bound on such effects" rather than refutation (Discussion ¶6).

5. **Upper bound / practical ceiling quantified?**
   PARTIALLY. The max-residual values themselves bound observable excess (z ≤ 2.53 → modest standardised residuals); no formal confidence bound on effect size — flagged MINOR; a formal bound would be ANALYSIS-REQUIRING and nonessential.

6. **"No supported excess" vs "no effect" distinguished?**
   ANSWERED. "not about the existence of shared history: the pairs simply fall where population-wide structure places them" (Results §2); "real historical contact will often be exactly as similar as broad structure predicts" (Discussion ¶4).

7. **Discussion acknowledges modest effects could be missed?**
   ANSWERED. Explicit sentence in Discussion ¶6.

8. **Negative result connected to methodological message strongly enough?**
   ANSWERED. The null result is the demonstration vehicle for the structural-null argument (Discussion ¶1); the cover letter carries the same connection.

## Findings

All eight questions answered; only residual gap is a formal upper bound on pair-specific effect size (MINOR, ANALYSIS-REQUIRING, nonessential — the paper's claim is calibration, not effect-size estimation).

Verdict: ADEQUATE — no edits required.
