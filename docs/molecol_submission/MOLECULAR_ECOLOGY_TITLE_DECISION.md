# Molecular Ecology title decision

## Decision: keep the current title
"Population structure defines the null expectation for pairwise genomic similarity: archaic-segment sharing across 66 human populations"

## Evaluation vs alternatives
1. "Population structure defines the null expectation for pairwise genomic similarity" (generic only) — loses the empirical-system transparency; risks reading as a pure methods paper better suited to Molecular Ecology Resources.
2. "Testing exceptional pairwise genomic similarity against population-wide structure" — drops the archaic-ancestry test bed from the title; less transparent.
3. "A structural null for exceptional pairwise genomic similarity" — vaguer; weaker discoverability.
4. **Current title** — first 65 characters contain the major keywords ("population structure", "pairwise genomic similarity"), states the inferential claim (not a method-name claim), and names the empirical system and scale honestly. No abbreviations. Keeps traceability with prior versions.

Verdict: keeps title; satisfies Wiley title guidance.
