# Molecular Ecology submission format audit

| Requirement | Status |
|---|---|
| Original Article; 8,000-word limit (Abstract+Intro+MM+Results+Discussion) | OK — ~4,768 total |
| Abstract ~250 words | OK — 245 |
| Keywords 4-6 | OK — 6 |
| Title keywords in first 65 chars; no abbreviations | OK |
| Running title <45 chars | OK — 41 |
| Free Format; consistent author-date references | OK |
| Order: Title Page/Abstract/Intro/MM/Results/Discussion/Acknowledgements/References/Data Accessibility and Benefit-Sharing/Author Contributions/Tables and Figures | OK — Acknowledgements moved before References; Data Accessibility and Benefit-Sharing + Author Contributions present; Funding/COI/Ethics/AI declarations included |
| Data archiving for review at submission; permanent archive at acceptance | OK — supplementary_data + data_archive zip included for review; Dryad/Zenodo permanent archive flagged as acceptance-stage author action; no fabricated DOI |
| Figures separate high-res files; legends in manuscript | OK — PNG+TIFF 300dpi |
| SI in separate files | OK — MOLECULAR_ECOLOGY_SUPPORTING_INFORMATION.docx + supplementary_data/ |
| Cover letter states Aims-and-Scope fit | OK — dedicated paragraph |
| COI statement, ORCID | OK — declared; ORCID on title page |
| Single-anonymous review | OK — author identity present on title page is fine |
| Fees | Traditional route $0; OnlineOpen APC optional ~$5,210; colour print optional |

Deviations vs Springer/GENETICS versions: Wiley author-date references + in-text commas/&; Acknowledgements before References; "Data Accessibility and Benefit-Sharing" heading; running title shortened to <45 chars; title-page Acknowledgements removed.
